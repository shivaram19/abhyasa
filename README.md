# Abhyāsa by Trayini

A public marketing landing page for **Abhyāsa**, a Trayini.ai initiative that helps Indian tuition centres, budget schools, teachers, and parents generate board-aligned practice worksheets, grade them with a phone scan, and adapt the next practice set for every student.

- **Live site:** `https://abhyasa.trayini.ai`
- **Parent organisation:** [Trayini.ai](https://trayini.ai)

## Name

_Abhyāsa_ (अभ्यास) is the Sanskrit word for sustained, repeated practice. Patañjali defines it in the *Yoga Sūtra* (1.14):

> “Sa tu dīrghakāla-nairantarya-satkārādarāsevito dṛḍhabhūmiḥ”  
> “Practice becomes firmly established when sustained with devotion, without interruption, over a long time.”

The product turns that idea into daily learning: personalised worksheets that grow with each student.

## Tech stack

- Next.js 16 (App Router)
- React 19 + TypeScript
- Tailwind CSS v4
- Radix UI primitives
- Lucide icons
